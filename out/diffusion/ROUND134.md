# 按目标难度出谱的接口 + 风格均衡（第 134 轮）

## 一、新增 `tools/target-diffusion.py`：给定目标定数，自动出谱
```
python3 tools/target-diffusion.py --ckpt out/models/diffusion32-cont.pt --target 16 --style 1 -o out/tgt16.osu
```
流程：按标定曲线估起点 → 采样 → 转谱 → Koishi 实测 → 偏差 >0.5 则按实测斜率修正 → 最多 3 轮。

实测：
| 目标 | 达成 | 轮数 | 判定 |
|---|---|---|---|
| **14** | **13.60** | 3 | jack |
| **16** | **16.24** | 1 | jack |

**「按指定难度写」现在是一个可调用的命令，不再是实验结论。**

## 二、风格均衡采样：修好了 speed，但 stamina 变弱
新增 `--style-balance α`（α=0 原始分布，α=1 完全均衡），四个 style 等权重训：

| style | 目标 | 均衡训练前 | **均衡训练后** |
|---|---|---|---|
| 0（tech） | tech | tech 0.81 ✅ | **tech 0.87** ✅ |
| 1（jack） | jack | jack 0.99 ✅ | **jack 0.47** ⚠️（仍是最高） |
| 2（speed） | speed | tech 0.77 ❌ | **speed 0.68** ✅ |
| 3（stamina） | stamina | stamina 0.66 ✅ | tech 0.63 ❌ |

**3/4 正确**（之前 2/3）。speed 修好了，代价是 stamina 塌到 tech、jack 的置信度下降。
原因：均衡采样把 stamina（原占 47%）的样本降权到 25%，它不再是「默认模式」，但样本量没变多。
