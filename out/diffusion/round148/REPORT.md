# 第 148 轮：发现音频条件数据集大面积错位（关键数据质量结论）

## 一、这轮最重要的一件事：踩音数据可能是错的
上一轮子代理交付了 `out/diff-data-audio-big/dataset.npz`（200 张谱 / 40 首歌 / 5279 窗口），
并报告「用 C 特征重建后与音符密度相关 0.43–0.77」。

我用两种独立方法复核，**都没有复现这个数字**：

### 方法一：逐包 offset 搜索（`tools/audio-offset-fix.py`）
对每个下载的谱面包，把音符时间按候选位移 ±2500ms 扫描，取「音符密度 vs 音频强度」相关最大的位移：

| 判定 | 包数 |
|---|---|
| ok（\|位移\| ≤250ms） | **15** |
| 位移过大（>250ms） | **17** |
| 相关过低（r<0.20） | 13 |
| 解析/音频错误 | 3 |

**28/48 的包最佳位移 >200ms**（示例：−2200ms、−2400ms、−2000ms、−700ms）。
方法论校准：用「已知按起音写的规则谱」跑同一搜索，只给出 −100ms（r 0.449→0.458），
**说明搜索没有过拟合**，这些大位移是真的。
**ok 子集的 r 中位 = 0.352**（比未校正的 0.213 高）。

### 方法二：数据集内部逐谱 X–C 相关（全局时间轴聚合，非窗口相对位置）
| 指标 | 值 |
|---|---|
| 中位 | **−0.062** |
| 均值 | −0.002 |
| p10 / p25 / p75 / p90 | −0.270 / −0.157 / +0.130 / +0.329 |
| **r ≥ 0.2 的谱** | **37/199（19%）** |
| r ≥ 0.4 的谱 | 12/199（6%） |

**约 81% 的谱，音频条件与音符密度基本无关。**

### 排除「谱面本来就均匀」这个解释
| 谱 | X–C 相关 | 密度 CV |
|---|---|---|
| 1091338-00-4K | +0.046 | **0.80**（起伏很大） |
| 1101819-05 | −0.214 | 0.30 |
| 1192012-00-4K | **+0.573** | 0.50 |
| 1233317-00 | −0.083 | 0.58 |

密度起伏大的谱也有 r≈0 → **不是「没信号」，是「错位」**。
而且**同一个包内不同谱结果矛盾**（1101819 里一张 +0.711、另一张 −0.214）
→ 指向「多曲 pack 里每张谱配了不同音频/不同 offset」这个具体问题。

## 二、这对「让扩散学会采音」意味着什么
1. 正在训练的音频条件模型**用的是这份数据**，如果错位占 81%，条件学不到真信号；
2. 但那个训练实验**设计了 A/B + 打乱条件的对照**——如果数据是坏的，
   带条件的模型会与无条件模型打平、且与「错位条件」无差别，**实验本身能自证数据质量**；
3. 所以不中断训练，等它的对照结果作为交叉验证。

## 三、下一步（明确）
1. **先用 offset 校正 + r 过滤重建音频数据集**：
   只保留「\|shift\| ≤250ms 且 r ≥ 0.25」的谱（按我的 index，至少 15/48 包可用），
   用校正后的 shift 重算 C（不是丢弃）；
2. 重建后再训音频条件模型，并用**打乱条件的对照**验收；
3. 若过滤后窗口数太少（<2000），需要继续扩歌——但**先质量后数量**。

## 四、另一条线的结果：分模型（第 145 轮收尾）
四风格分模型：**0/4 达标**（单模型同口径 1/4）。
- 渗漏确实消失：tech/jack 分离度 **48.8×**（数据集 8.4×，单模型 4.3×）；
- **未达标主因是「步数被四等分」**：每模型 567 步 vs 单模型 2250 步；
  同一 tech val 上分模型 x0 MSE 0.0847 > 单模型 0.0766；
- **能力仍在**：tech 双倍步数（1125 步）p132 从 0.312 → 0.363（外推 2250 步 ≈0.41 ≈ 单模型 0.396）；
  speed 在密度匹配点达到 **0.610**（数据集 0.614，Δ−0.004）；
- 结论：**分模型方向对，但要给足步数**（每模型 2250 步 ≈ 4×25min）。

## 五、结论
**这轮的核心不是「又训了一个模型」，而是发现「踩音的数据基础还不可靠」。**
在修好数据之前，任何音频条件训练都可能是白跑。这比多训一个模型重要得多。
