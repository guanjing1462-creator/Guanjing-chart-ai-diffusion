# 生成谱面客观评估（EVAL）

> 目的：回答「生成的谱到底好不好」。训练损失是逐格 BCE/MSE，它奖励“把每一步的占用概率预测对”，
> 并不约束踩音、段落、键型、可弹。本报告用 `tools/eval-generated.py` 把这些拆成可测量的四组指标，
> 拿 **人类基线（80 张）** 做尺子，量 **扩散谱**（`diffusion4k.pt` / `diffusion4k-x0.pt` 两个真权重 + 1 个随机权重噪声对照）与 **规则生成器谱**。

**一句话结论**：扩散谱目前的问题不是“差几个百分点”，而是 **① 结构上无法踩音 ② 没有段落重复（8 行窗重复率 0.000，人类中位 0.215）③ 密度/键型不可控（占位率 0.20~0.37、jack 率 0.19~0.85、手位移 0.44）**；
而它「键型余弦 0.95~0.99、远超人类 0.75」的高分是 **指标饱和造成的假象**——随机权重同样 0.999。

## 1. 方法

### 1.1 只读依赖（全部未修改）

| 组件 | 用途 |
| --- | --- |
| `tools/audit-chart.py` 的 `parse_osu()` / `rows_of()` | 全仓库统一谱面解析器（importlib 加载，不复制解析逻辑） |
| `tools/gj/batch-koishi.mjs` | 观景台难度模型：`diff`（11~17，低于 11 返回 null）+ 5 维键型 `probs` |
| `tools/playability-check.py` | 可弹性冲突口径的来源（同列极速连打 / 单侧过载），本轮按任务要求收紧到 55ms |
| `out/multisong/*-fx.json` | 6 首歌的起音信息（`peaks` 细网格谱峰 + `onset`/`accent` 每 1/16 格强度） |
| `/tmp/d_{tech,jack,speed,stamina}.json` | 人类包质心（batch-koishi 输出数组的 `probs` 均值） |
| `tools/sample-diffusion.py` → `tools/roll-to-osu.py` | 扩散采样出谱链路（只调用） |

新工具只有一个：**`tools/eval-generated.py`**（输入一个或多个 `.osu`，输出 JSON + 中文对齐表格）。

### 1.2 指标定义

| 组 | 指标 | 定义 | 为什么是它 |
| --- | --- | --- | --- |
| 踩音 | 峰距 mean/median/p90、`within20`/`within40` | 音符时间→最近起音谱峰的绝对误差 | 传统对音口径，可与 `audit-chart.py` A 段对齐 |
| 踩音 | **起音格位百分位**（onset / accent，0.5 = 随机） | 谱面用到的 1/16 格位上，音频起音强度的百分位均值 | 本工程生成链路真正吃的是 `onset`/`accent` 曲线，不是原始谱峰；峰距在 1559 个峰的稠密歌上被压平 |
| 踩音 | **机会基线** `chance_grid` / `chance_uniform` / 平移扫描 | 同音符数、同时间跨度随机撒在 1/16 网格 / 整条时间轴上、以及整体平移 ±80ms 后的峰距 | 没有基线就不知道「36ms」是好是坏——实测随机撒点也是 36ms |
| 结构 | 音符率 nps、行率 rps、npr、和弦率、LN 占比 | 常规密度量 | 损失下降最容易体现在这里 |
| 结构 | **jack 率**（同列 ≤2 个 1/16 格连续） | 相邻行间隔 ≤2 格且共列的比例 | 模式塌缩最敏感的量 |
| 结构 | **1/32 占比** | 行间隔落在 1/32 拍（±50%）的比例，按谱面自身 bpm 归一到 1/16 格计数 | 直接量“节奏细分能力”，回答“会不会只有均匀 1/16” |
| 结构 | **手位移** | 相邻行「重心列」差的绝对值均值（单位：列宽，0~3） | 移动/位移型谱 vs 原地连打的区别 |
| 结构 | **行重复率（8 行滑窗）** | 8 行滑窗签名中「与之前某个窗口完全相同」的比例 | 段落/乐句结构的最低证据；噪声没有重复，人类谱有 |
| 结构 | 占位率 | 音符数 / (1/16 格行数 × 4) | 与数据集占位率 0.4072 直接可比 |
| 键型 | 与四包质心余弦、最佳包、最佳余弦 | 5 维 `probs` 的余弦相似度 | 与第 123 轮基准（jack 0.95 / stamina 0.71 / tech 0.66 / speed 0.61，人类包内留一）同口径 |
| 难度 | Koishi `diff` / `tier` | 观景台数值难度 | null = 模型判为低于 11 级（模型下限），不等于 0 |
| 可弹 | 冲突/分、单列最高连打频率 Hz | 同列 <55ms 冲突 + 单侧（0/1 或 2/3）55ms 内 ≥3 音；另给单列最高连打频率 | 55ms 是“物理不可能”的门槛；1/16 网格（110ms）下这个门槛永远不触发，所以补一个“单指要按多快” |

**注**：`pattern` 标签本轮不参与任何结论——人类谱自身一致率只有 42~45%，只看 `probs` 与 `diff`。

### 1.3 数据与运行约束

- **人类基线**：`out/packs/{tech,jack,speed,stamina}` 各有 484~1051 张 4K 谱，每包用 `--seed 0` 随机取 **20 张**，共 80 张（可复现）。
- **扩散谱**：
  - `扩散·ep24`（4 张）：`out/models/diffusion4k.pt`（epoch 24，val 0.2155）→ `test-real-s2d3`、`test-real-s2d3-bpm200`、`s1d2-seed0`（仓库已有）+ 本轮新采样 `diff-ckpt24`；
  - `扩散·x0`（2 张）：`out/models/diffusion4k-x0.pt`（epoch 2，val 0.7508）→ `--num 4` 采两轮（seed 0 / 1），`roll-to-osu.py --concat --bpm 136.3`；
  - `扩散·随机权重`（2 张）：`test-random`、`test-random-ln`（`--random-weights` 噪声基线）。
- **规则生成器**（4 张）：`out/all/Heart_Fraction--{Hybrid,Jack,LN,Tech}--D22.osu`（同曲同目标难度，唯一能与音频对齐的一组）。
- **批次约束**：所有 Koishi 调用一次 ≤ **20 张**；80 张人类基线按包分 4 片跑，峰值内存远低于 2GB 上限。
- `--koishi-mode per-file` 是本轮被迫加的模式：`batch-koishi.mjs` 内部对每张谱最多等 400s，且分析是“同步触发 + 异步完成”——被放弃的谱仍在后台烧 CPU，**一张病态谱能把整批拖到几十分钟**（实测 jack 包整批卡了 >12 分钟无输出）。逐张模式把单张上限压到 60~120s，坏一张只赔一张。

## 4. 结论：扩散谱目前差在哪几个指标

### ① 踩音：不是“差”，是**结构上做不到**（差距类型不同于规则谱）

- `diffusion4k*.pt` 的 `cond_dim = 0`（无条件 U-Net），`roll-to-osu.py` 从 `t=0` 按 1/16 格（110.05ms）铺，`AudioFilename` 是占位的 `song.ogg` → 生成谱与任何歌都没有时间对应关系，**踩音指标只能跳过**。
- 规则谱也不见得多会踩音，但它至少挂在歌上：accent 格位百分位 **0.637**（随机 0.5），onset 只有 **0.542**（基本等于随机）；峰距 **35.7ms** 与“随机撒点”的 **36.2ms** 无差别——平移扫描的最好平移也只有 33ms，说明头部 10% 的单点对音都算不上强。
- 结论：**规则谱是“弱踩音”，扩散谱是“零踩音能力”**。要追上，必须接音频条件：本轮评估的两个权重（`diffusion4k.pt` / `diffusion4k-x0.pt`）都是 `cond_dim=0`。
  好消息是写作期间已有真正带条件的权重落盘（`out/models/diff-cond-seed{0,1,2}.pt`：`cond_dim=32`、`cond_channels=4`、`audio_cond=out/diff-data/cond-windows.npz`、epoch 12 / val 0.3016）——
  同一套评估只需把 `--ckpt` 指向它、并用 `sample-diffusion.py --cond ... --cond-index N` 采样，就能直接量“接上音频条件后踩音格位百分位从 0.5 涨到多少”。本轮没跑它：那些权重在评估期间正被别人持续覆写。

### ② 段落结构：行重复率 **0.000**，比人类 79/80 张都低

| | 8 行窗行重复率 |
| --- | --- |
| 人类基线（80 张） | 0.259 ± 0.189（中位 0.215，p10 0.043，最小 0.001） |
| 规则生成器 | 0.217 ± 0.048（中位 0.217，与人类中位同一水平） |
| 扩散·ep24 | **0.000 ± 0.000（4/4 张）** |
| 扩散·x0 | 0.025 ± 0.006 |
| 扩散·随机权重 | **0.000（2/2 张）** |

人类谱里只有 9/80 张低于 0.05、1/80 张低于 0.005；扩散谱 100% 落在这个尾巴上，且 **训练过的权重与随机权重同为 0.000**。
这意味着模型产出的是「无重复的均匀流」：没有乐句、没有段落回环、没有 2/4 小节反复——这是它“听起来像一坨”的最硬证据，也是损失完全不管的东西。

| 扩散·ep24 | 0.365（其中 1 张 0.201 = 人类最低值） | 0.456（**1 张 0.19、3 张 0.54**） | 1.05 | **0.000** |

| 规则生成器 | 0.456 | 0.299 | 1.20 | 0.207 |

- 同一模型的两个窗口密度可以直接差一倍（ep24 采样统计：4 个窗口音符数 `[68, 41, 151, 148]`，占位率 0.1992；x0 是 `[159,167,159,132]`，占位率 0.3013；数据集 0.4072）——**采样方差远大于人类包内方差**。
- `test-real-s2d3` 与其 `--bpm 200` 版本 nps 从 15.4 变 22.6，但 jack 率、npr、占位率一字不差（0.54/1.85/0.423）——说明模型对“速度参数”并不敏感，只是在坐标系上被拉伸。
- 全程 LN 占比 **0.000**（`roll-to-osu.py` 用 `--ln none`），人类 0.022、规则谱 0.045。

### ④ 方法学警告：**“键型余弦 0.95~0.99”是假象，不能用它论证质量**

| | cos·jack | cos·stamina | 最佳质心余弦 |
| --- | --- | --- | --- |
| 人类 jack 包（同包留一基准 0.95） | 0.896 ± 0.288 | 0.855 ± 0.264 | 0.944 ± 0.154 |
| 扩散·x0（**训练过**） | 0.991 | 0.973 | 0.991 |
| 扩散·随机权重（**没训练过**） | **0.999** | 0.946 | **0.999** |
| 规则生成器（多流派混合） | 0.279 | 0.283 | 0.611 |

5 维 `probs` 空间里，jack 质心就是 `{jack 0.935, tech 0.030, speed 0.021, stamina 0.014, ln 0.000}` 这种近 one-hot 向量，**任何“纯 jack 或纯噪声”的谱都会拿到 ~0.99**；随机权重谱甚至比人类同包还高。
反过来，混合型规则谱 0.611 却被这个指标判成“最不像人”。所以：**余弦只能当“是否塌缩成单一键型”的指示器，不能当质量分**；`best_cos > 0.95` 应当读作“塌缩警告”而不是“人类水平”。

### ⑤ 唯一一件扩散做得比规则好的事，也不是它做对了

扩散谱 55ms 冲突 **0.00/分**，规则谱 **65.9/分**（21.7~95.0，人类 max 只有 22.8）——但这是因为 1/16 网格 110ms 根本产生不了 <55ms 的同列间隔，不代表好弹：规则谱的单列最高连打 **27.8 Hz**（人类中位 13.3、p90 20.0、>25Hz 只有 1/80 张），是真正物理上弹不了的部分；扩散谱 9.1~13.3 Hz 落在人类正常范围，但它的 jack 率是人类的 2~3.6 倍、且没有任何延音。

### ⑥ 难度维度暂时不可用

扩散 4 张里只有 1 张拿到 `diff`（14.03），随机权重反而拿到 12.01，其余全部 null（<11 级）；人类 61/80 有值、均值 14.11。**用 diff 说不清扩散难不难**，因为覆盖率只有 1/4——要判难度，先让谱面密度追上人类（nps 22.0 / 占位 0.412）。

### 已知局限（写论文/汇报时必须带上）

1. `diff` 是模型内 `11 ≤ 定数 < 17` 的输出，null 只能读“判为低于 11 / 超范围”，不能读“难度=0”；两组 null 比例都高（人类 19/80）。
2. 55ms 可弹性门槛在 1/16 网格下不可触发，冲突数 0 不等于可弹；要配“单列最高频率”一起看。
3. 余弦相似度会奖励塌缩（见 ④），**不能单独使用**。
4. 扩散谱时长 ~56s（4 个窗口），人类样本中位 146s；短谱的爆点密度天然被摊平，密度类指标需按 nps/占位率看而不是绝对音符数。
5. 人类基线是每包 20 张随机样本（seed 0），跨 11~17 级全区间；`diff≥11` 子集（61 张）与全集（80 张）的偏差：
   nps +4.5%、行重复率 +6.1%、1/32 占比 +5.2%、手位移 +2.3%、占位率 +1.0%，**jack 率 -15.9%**、冲突/分 +8.0%。
   即子集更密、更少 jack，但“扩散谱 jack 偏高 / 行重复为 0 / 1/32 为 0”的结论方向不变。
6. 本轮没有做“听感”验证，也没有做时间轴上的段落切分——行重复率只是段落结构的最低证据。
