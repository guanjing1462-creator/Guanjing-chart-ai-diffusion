# 第 138 轮：在无泄漏数据上正式重训（结果：泄漏对损失影响很小）

## 一、这次训练用的是第一份可信训练集
| 项 | 值 |
|---|---|
| 数据 | `out/diff-data-grouped/dataset.npz`（95,574 窗口，[4,256]，1/32 网格由**真实红线 beatLength** 定） |
| 划分 | **按同源组**：train 87,009 窗（2299 谱 / 141 组）、val 5,025（148 / 17）、test 3,540（124 / 17） |
| 跨集交集 | chart_id 0 / group_id 0 / 共享谱窗口 0 |
| 训练器 | `tools/train-diffusion32-grouped.py`（只按 `split` 键取数，**不做随机划分**） |
| 采样策略 | 每 epoch 从 train 抽 8000 窗，**单组上限 300 窗**（避免最大组 32,513 窗主导） |
| 配置 | x0 参数化、base 48、batch 32、threads 1、12 epoch 预算 |

## 三、**泄漏到底影响多少？答案是：影响很小**
用同一份权重，在同规模（5025 窗）的两种验证集上测：

| 验证集 | 池化损失 | 组均损失 |
|---|---|---|
| **A：split==1（无泄漏，17 组）** | **0.0660** | 0.0669 |
| B：split==0 抽样（等价旧的泄漏式验证，139 组） | 0.0670 | 0.0663 |
| 差值 B−A | **+0.0010（+1.5%）** | −0.0006 |

**结论：对「重建式»扩散损失而言，窗口级泄漏没有造成明显虚高。**
原因：模型 0.44M 参数学的是局部结构，不记忆具体谱面；同曲不同窗口仍是不同样本。

**但这不等于旧的验证方式没问题**——数据代理推算：旧数据集按窗口 10% 做 val 时，
**约 97.2% 的谱会同时出现在训练和验证中**（我独立按 88787 窗 / 2617 谱重算，结果一致）。
正确的做法仍然是按组划分；只是这次量化表明「旧 val 数字的乐观偏差只有 ~1.5%」，
而不是之前担心的量级。**这个结论对后续所有训练都适用，值得记住。**

### 补充：记忆分解与 test 集（子代理额外做的）
- 9 轮实际训练过 35,599 窗 = train 的 40.9%；B 集里 81% 见过，但 **B_seen 0.0681 > B_unseen 0.0669**
  → **见过的窗口并不更准，这份预算下看不到记忆红利**；
- **test 集只跑一次**（124 谱 / 17 组，从未参与选择）：池化 **0.0640** / 组均 **0.0621**，
  **不比 val 差**（val 0.0660/0.0669）→ 本轮 val 数字可信；
- 分风格 test 池化：style0 0.0614 / style1 0.0561 / **style2 0.0868（speed 最难）** / style3 0.0508。

## 四、新模型的生成侧表现（我的独立验收）
用修好的采样器（阈值 0.2，200 BPM 转谱，6 窗口）：

| 难度条件 | 占位率 | p132（格口径） | **Koishi 难度** | 判定 |
|---|---|---|---|---|
| 0.2 | 0.1214 | 0.066 | 低于 11（None） | stamina |
| **0.5** | **0.2173** | 0.158 | **14.05**（Delta mid） | jack |
| **0.8** | **0.3089** | **0.328** | **16.58**（Thaumiel Eta low） | jack |

数据集参考：占位率 0.1986、p132 0.2637（人类 0.300，格口径）。

**难度条件单调性 4/4 风格全部成立**（子代理 4 style × 3 档 × 2 窗）：
占位率 style0 0.077→0.215→0.291、style1 0.088→0.215→0.277、style2 0.086→0.220→0.288、style3 0.080→0.214→0.276。

**但 p132 跨风格严重失配**：diff 0.5 时 style0 **0.573** / style1 **0.115** / style2 **0.593** / style3 0.292
（数据集 0.2637）→ **tech/speed 变成「满格连打」，jack 又过稀**，节奏规整度没学到。
→ **占位率与 p132 都随条件单调上升，难度随条件单调上升（14.05 → 16.58），
干净数据重训没有破坏「按指定难度写」。**

## 五、这轮的诚实结论
1. ✅ 第一份**可证明无泄漏**的训练/验证集可用（三条断言全 0 交集）；
2. ✅ 按组划分重训成功，val 0.0660（组均 0.0669），训练/验证基本不 gap → 无过拟合；
3. ✅ 泄漏量化结果：**仅 +1.5% 虚高**，比预期小得多——之前数字大体可信；
4. ✅ 难度可控性在干净数据上**保留**（条件 0.5→14.05、0.8→16.58）；
5. ⚠️ 键型仍以 jack 为主（条件 0.5/0.8 都判 jack），style 分化还需单独处理；
6. ⚠️ 数据侧已知限制：LN 只存起点、2601 张谱缺音频（跨组同曲无法排除）、
   14.61% 音符是 1/48 三连音被吸到 1/32 格（格口径 p132 偏高）。
