# 扩散模型第二轮：参数化、密度与两个被推翻的结论（第 127 轮）

## 一、这轮最重要的：**发现一个会推翻结论的 bug**
我给训练脚本加的 `--pred {eps,x0,v}` **只传给了验证函数，没传进训练损失**：

```python
# 错误版（第 192 行）
loss = diff.loss(model, X[idx], S[idx], D[idx])        # mode 默认 'eps'
# 验证函数却传了 a.pred
l = diff.loss(model, Xte[sl], Ste[sl], Dte[sl], a.pred)
```

后果：
1. `--pred x0` 的训练目标其实是 **eps**，验证损失却按 **x0** 算；
2. 所以「训练 0.29 / 验证 0.85 且在涨」不是过拟合，是**两个不同的损失量**；
3. 更关键：`diffusion4k-x0.pt` 里存的是 eps 网络，采样器却按 x0 解释它
   （把 N(0,1) 的 eps 输出直接当概率，阈值 0.5 ≈ 统计 P(N>0.5)=0.309）——
   **实测的 0.281 占位率是统计巧合，不是模型学到的密度**。

**结论：此前「x0 比 eps 好（0.281 vs 0.115）」的有效证据为零，必须重做。**

已修复（共享脚本第 358 行）：
```python
loss = diff.loss(model, X[idx], S[idx], D[idx], mode=a.pred, cond=cb)
```

## 二、第二个被推翻的结论：**风格条件完全不生效**
用现有权重采样不同风格，结果几乎一样：

| style | 占位率 | Koishi 判定 | jack | speed | stamina | tech |
|---|---|---|---|---|---|---|
| 0（tech） | 0.307 | jack | **0.80** | 0.14 | 0.04 | 0.03 |
| 1（jack） | 0.294 | jack | **0.81** | 0.12 | 0.04 | 0.02 |
| 2（speed） | 0.300 | jack | **0.80** | 0.14 | 0.03 | 0.03 |

**三个风格生成出来的东西在第三方模型眼里是同一个东西。**
可能原因：数据分布严重不均（stamina 14390 窗口占 47%、jack 4339、speed 5290、tech 6532），
模型退化成「输出数据集的众数模式」，条件嵌入被忽略。

## 四、这轮的方法论收获
1. **训练指标必须自己验证口径**：`--pred` 这种开关一旦只在一处生效，就会产出「看起来很好、实际错位」的模型；
2. **风格/难度条件是否生效，必须用第三方模型做对照采样**，不能只看损失；
3. **损失下降 ≠ 出谱质量**，最终只能用采样占位率 + 踩音 + 键型向量来验收。
