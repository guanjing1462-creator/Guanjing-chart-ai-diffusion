# 第 151 轮：修正上一轮的采音结论——信号比我说的大得多，但只到 250ms 粒度

## 一、我上一轮的方法学错了（必须更正）
第 150 轮我写「真正的对齐信号 = 配对 − 错配 ≈ 0.036~0.080」。**这个基线选错了。**

- 我拿「**错配样本**对**它自己给定**的 C」当无采音基线（0.171）；
- 但一个**服从指令**的模型，无论给它哪份 C 都会跟随——所以它「对给定 C」当然高。
- **正确的无采音基线**是「**错配对真 C**」（≈0 或负）。

用正确基线重算：

| 对照 | val (24 窗) | test (20 窗) |
|---|---|---|
| 人类真谱 r250 | 0.351 | 0.394 |
| A（无条件） | 0.080 | 0.019 |
| **B（配对，对真 C）** | **0.207** | **0.165** |
| B（错配，对**真** C） | **−0.058** | **−0.041** |
| **配对 − 错配（真正的对齐信号）** | **+0.223**（24 胜 0 负，p=1.2e-7） | **+0.166**（p=4.8e-4） |
| 配对 − A | +0.142（p=3e-5） | +0.149（p=3.8e-6） |

**所以采音信号是 +0.223，不是 0.036。** 我上轮把最强的证据说小了。

## 二、但有个硬上限：相位分辨率只有 **≈160ms（4 格）**
- 把条件平移 **+1 格（≈40ms）**：对给定 C 的相关从 0.207 掉到 **0.002**（p=3.9e-6）；
- 平移 **+4 格（≈160ms）**：**不退化**（0.157，p=0.64）。

两条合起来说明：模型的条件分支是 **stride=4**（每 4 个 1/32 格才有一个条件位置），
所以它**跟随的是 ~150ms 尺度的包络**，±1 格塌掉是下采样混叠，不是「学到了 40ms 相位」。
证据：`p_odd_hi`（音符落在高强格的奇数格比例）配对 = 错配 = 0.727，人类 0.813
→ **1/32 格级「踩格」没学到**。

**结论：采音学会了，但只到 250ms 包络粒度；要到 1/32 踩格，必须把条件分支改成 stride-1/2。**

## 六、方法学教训
**验证「条件是否起作用」时，基线必须是「把条件给错、再用真值评估」**，
而不是「把条件给错、再用错值评估」——后者会惩罚一个听话的模型，把真实信号严重低估。
我上一轮就是这么错的。
