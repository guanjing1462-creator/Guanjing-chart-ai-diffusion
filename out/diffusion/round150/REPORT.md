# 第 150 轮：**采音第一次被学会**（部分）+ LN 学会写但长度偏长

## 一、采音：从「完全没有」到「可测量」
数据用上一轮修好的 `out/diff-data-audio-fixed`（114 谱 / 2887 窗 / 25 歌，X–C 相关中位 +0.498）。

在干净数据上重训两档（同 init-seed、9 epoch）：
- **A：无条件**（`--cond-dim 0`）val 0.0818
- **B：音频条件**（`--cond-dim 32`）val 0.0809

**关键验收：24 个验证窗，比较「配对条件 / 错配条件 / 零条件」下的采音指标**

| 组 | r250 中位 | r1000 中位 |
|---|---|---|
| **人类真谱（同 split）** | **0.351** | **0.476** |
| A（无条件） | 0.080 | −0.005 |
| **B（配对条件）** | **0.207** | 0.144 |
| B（错配条件，打乱 song/start） | 0.171 | 0.194 |
| B（零条件） | 0.009 | −0.058 |
| **B（占用校准后·配对）** | **0.274** | **0.307** |
| B（占用校准后·错配） | 0.194 | 0.197 |

### 怎么读这组数
1. **A 只有 0.08（≈无采音）**，B 到 **0.207–0.274** → **条件确实带来了采音**；
2. 但 B 的「错配」也有 0.171–0.194，说明其中一部分是「密度先验」而非真对齐；
   **真正的对齐信号 = 配对 − 错配 ≈ 0.036（未校准）/ 0.080（占用校准）**；
3. **相位敏感性**：把条件整体平移 ±1 格后再对**其给定 C** 评估，相关掉到 0.002–0.116
   → 模型确实在跟「给它看的那份 C 的相位」走，不是凭声音响度乱猜；
4. 人类是 0.351/0.476，**我们达到约人类水平的 60%**。

**结论：采音「学会了但还不够」——第一次有可测量的效果（A 0.08 → B 0.21–0.27）。**

## 二、LN：**会写了，但写得偏长**
数据 `out/diff-data-ln`（83,027 窗，X 占用 / L LN体 / H LN头），人类基准：
LN 头 **3.364 个/窗**、LN 体格 28.117 格/窗、长度中位 **5 格**、p95 21–25。

训练 8 通道（X|L）+ 基线对照（LN 头当普通音符、L 目标全 0）：

| 模型 | LN 头/窗 | LN 体格/窗 | 长度中位 | p95 |
|---|---|---|---|---|
| λ=1.0 | **3.00–3.30** | 30.4–31.1 | 8–9 | ~20 |
| λ=2.0 | 4.20–4.70 | 44.8–45.1 | 9 | 21 |
| **基线（无 LN 监督）** | **0** | **0** | – | – |
| **人类** | **3.364** | **28.117** | **5** | 25 |

### 结论
1. **「写 LN」学会了**：λ1 的头数 3.0–3.3（人类 3.364，误差 −2%~−11%），体格 30.4（人类 28.1，+10%）；
   **基线在任何阈值下都是 0 个头**（Q 最大仅 0.075）→ 能力确实来自 LN 体监督，不是碰巧；
2. **「写多长」未达标**：中位 8–9 格 vs 人类 5（+60%~80%）；
   具体缺陷：**几乎不写 2–4 格短长条（12% vs 人类 37%）**、9–16 格过多（41% vs 17%），
   但长尾（p95≈20-21 vs 25）基本对得上；
3. λ=2.0 只提高召回（头 +40%、体格 +60%），**没有修正长度分布**。
