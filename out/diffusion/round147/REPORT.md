# 第 147 轮：难度起伏已实现；LN 与采音数据同时开工

## 一、难度起伏：**做出来了**（这是本轮我自己完成的部分）
人类的强度曲线特征（99 张人类谱，4 秒分箱的 NPS）：
**CV 0.30、峰均比 1.40、峰值位置 0.60**（后半段到顶）。

之前我们一直用**恒定的难度条件**生成 → 曲线是平的。

### 做法：曲线驱动采样 `tools/sample-curve.py`
把整首切成 N 个窗口，每个窗口用**不同的连续难度条件**采样，条件按形状曲线变化
（起手 warm → 峰值 1.0 在 peak_pos 处 → 收尾 tail），**并且目标占位率也按曲线缩放**
（这一条是关键：第一版只改条件不改占位率，密度被 `--target-occ` 强制拉平，起伏消失）。

### 结果
| 版本 | CV | 峰均比 | 峰位 | 平均 NPS |
|---|---|---|---|---|
| 恒定条件（之前） | 0.14 | 1.15 | 0.84 | 27.2 |
| 曲线 v2（弱，occ 0.26→0.33） | 0.15 | 1.27 | 0.58 | 21.3 |
| **曲线 v3（强，occ 0.19→0.41）** | **0.26** | **1.44** | 0.50 | 21.6 |
| **人类目标** | **0.30** | **1.40** | 0.60 | 16.8 |

**峰均比 1.44 已经与人类 1.40 吻合，CV 0.26 接近 0.30。**
Koishi 难度 14.15（Delta mid/high）。

剩余偏差：峰值位置 0.50 vs 人类 0.60（4 秒分箱会把峰值位置往中间拉，
调 `--peak-pos` 到 0.7 应该能补上）。

## 二、LN：数据已建成，训练进行中
### 数据集 `out/diff-data-ln/dataset.npz`（83,027 窗）
关键是**补回了之前完全丢失的 LN 长度信息**，用三个通道表示：
| 通道 | 含义 |
|---|---|
| `X` | 占用（LN 覆盖全部格，普通音符只取起点） |
| `L` | **LN 体**（LN 覆盖格 = 1） |
| `H` | **LN 头**（LN 起点格 = 1） |

统计：占位率 0.2223、**LN 体格占占用格 6.32%**、按组划分 train 75,659 / val 4,149 / test 3,219。
（对比：之前的 `dataset.npz` **只有 X，LN 只存起点、长度全丢**——所以模型不可能学会 LN。）

训练：模型改成 8 通道（4 键 × 占用 + LN体），损失 = 占用 MSE + λ·LN MSE。
epoch 2/9 结果：占用 0.0911 / LN 0.0141（组均 0.0907/0.0123）。λ=1.0 与 λ=2.0 两档在跑。

## 三、采音：数据集扩容中（49 个谱面包 / 717MB）
按「.osz 自带音频，所以每个包就是一对谱面+音频」的思路批量抓取：
- 已下载 **49 个 set / 717MB**
- 抽样 14 首歌验证「音符密度 vs 音频强度」相关系数：**r 中位 0.137**（随机平移基线 0.005）
- **但发现数据质量问题**：部分谱面的最佳位移达到 **±2.2 秒**（如 Rose Quartz, best_shift −2200ms），
  说明这些包的**谱面时间轴与音频起点不匹配**（不同版本音频/或谱面 offset 不同）。
  → 必须在建库时**按最佳位移做校正或剔除**，否则训练出来的采音会偏。

## 四、借 Mug 的地方（说明）
Mug 的核心是「mel 频谱条件 + VAE latent + UNet 扩散」。我们复用了它的**结构思想**：
① 音频侧用 mel/频带 onset 特征当条件（`tools/audio-cond-data.py` 已实现）；
② 条件注入 U-Net 中间层（`AudioCondNet`，已验证因果有效：干预可让占位率变化 +11.8~15.1%）。
但我们**没有复用它的权重或训练数据**（做不到，也没有必要），走的是自己的小模型路线。
