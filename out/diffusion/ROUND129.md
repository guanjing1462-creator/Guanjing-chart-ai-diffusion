# 扩散模型第四轮：补上段落结构 + 定位难度偏低的原因（第 129 轮）

## 一、段落结构：从 0.000 补到 0.210（人类 0.259）
扩散生成是逐窗口独立采样，**没有任何跨窗口结构**（8 行窗重复率 0.000，连随机权重也是 0）。
新增 `tools/structure-post.py`：把谱面切成 8/16/32 行的段落，选若干段整段复制到别的段位置
（时间平移），密度与键型分布不变，只增加长程重复。

| 配置 | 8 行窗重复率 | npr | 人类参考 |
|---|---|---|---|
| 扩散原始 | **0.000** | 1.89 | 0.259 |
| 后处理 repeat=0.35 | 0.139 | — | |
| **后处理 repeat=0.5** | **0.210** | 1.94 | ✅ 接近人类 |
| repeat=0.6 / 0.7 | 0.178 / 0.195 | 1.93 / 1.89 | 重叠覆盖导致回落 |

**结构问题用规则后处理就能补上**，不需要重训模型。这也印证了一个工程判断：
扩散负责「局部键型像人」，规则负责「全局结构像人」，两者互补。

## 二、为什么 Koishi 不给扩散谱难度值
之前一直显示「难度 None」，这轮查清了原因：

```
数字难度提示: BelowScope
警告：Koishi 仅计算 11 ≤ 定数 < 17；预测低于 11，不输出难度。
```

**不是解析失败，是模型认为我们的谱比 Alpha（11 级）还简单**，尽管它有 15.9 NPS。

对照数据（同一把尺子）：

| 谱 | NPS | npr | 1/32 占比 | 手位移 | Koishi 难度 |
|---|---|---|---|---|---|
| 人类包均值 | 21.95 | 1.63 | 0.300 | 1.22 | 14.11 |
| 规则生成器（GJ） | 15-20 | 1.37-1.55 | 0.5-0.7 | 1.18-1.34 | 13-16 |
| **扩散生成** | **15.9** | **1.89** | **0.000** | **1.03** | **<11** |

三条结构性差异导致难度判低：
1. **1/32 占比恒为 0**——扩散输出全在 1/16 网格上（窗口分辨率限制），
   而人类 0.300、规则生成器 0.5-0.7。没有 1/32 就没有「密集连打」的难度来源；
2. **节奏过于均匀**——每行间隔都是 110ms，没有长短变化，压力曲线是平的（无峰值）；
3. **手位移偏低**（1.03 vs 人类 1.22）——模型"粘连同列"（实测同列相邻相关 0.33 vs 真实 0.21）。

## 三、结论与下一步
| 项 | 状态 |
|---|---|
| 密度 | ✅ 达标（0.4072 = 训练集） |
| 段落重复 | ✅ 用后处理补到 0.210（人类 0.259） |
| 1/32 细分 | ❌ 分辨率限制，需把窗口步长从 1/16 改成 1/32 |
| 节奏变化 | ❌ 模型输出过于均匀 |
| 难度可控 | ❌ 判 <11，无法用于「按指定难度写」 |
| 踩音 | ❌ 无音频条件（另一子代理在做） |

**下一轮最关键的一步：把数据表示从 1/16 网格改成 1/32 网格。**
这是 1/32 占比为 0 的直接原因，也是难度判不上去的主因；
改表示后需要重训（预计耗时与这轮相当，约 30-40 分钟）。
