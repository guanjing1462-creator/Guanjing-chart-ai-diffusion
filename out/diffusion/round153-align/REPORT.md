# 第 153 轮：条件注入改多尺度全分辨率 —— 相位分辨率 160ms → 40ms

> **一句话结论**：早前确认的结构性瓶颈（`Conv1d(..., k=4, s=4)` 单点注入把条件压到 64 位置，
> 相位分辨率 ≈4 格 ≈160ms）**已经解除**。同一数据、同一 `init-seed`、同样 15 epoch 下，
> 多尺度全分辨率注入（S1）在主判据 `p_odd_hi` 上**显著高于** stride=4 单点注入（S4）：
> **0.7653 vs 0.7401**（bootstrap 95% CI [+0.0070, +0.0493]，单侧 p=0.0005），
> 1 格（≈40ms）对齐 **0.504 vs 0.440**（p=0.022），且 **±1 格平移**
> 让 S1 的输出真的跟着移动（S4 不跟）、**±4 格**两者都跟 —— 分辨率边界正好落在 1 格。
> 独立复现（test，未参与选模）更强：`p_odd_hi` **0.781 vs 0.729**（+0.052，p<1e-4）、
> 1 格对齐 **0.544 vs 0.322**（+0.118，p=1.7e-4），**S1 与人类 0.811 的差已不显著**（S4 仍显著更低）。
> 边界：`r250/r1000` 两档无显著差 —— 多尺度注入买到的是「细相位」而不是「更大的跟随幅度」。

## 1. 架构改动（新文件 `tools/train-diffusion32-align.py`，旧训练器一字未改）

### 1.1 改动前后

| | 旧（S4：`--inject mid4`，与 `train-diffusion32-mel.py` 逐字段一致） | 新（S1：`--inject multi`） |
| --- | --- | --- |
| 条件编码 | `Conv1d(32→32,k3)` ×2 → **[B,32,256]** 保持全分辨率 | 同（**不加 stride**） |
| 注入投影 | `Conv1d(32→96, k=4, s=4)` → **[B,96,64]** | 每层各一个 `1×1 Conv`，先 `AvgPool1d(k)` 降采样 |
| 注入位置 | **只加在 mid**（64 位置，1 位置 ≈ 4 格 ≈ 160ms） | **加在 e0/e1/e2/mid 四个层级** |
| e0（256 位置，48 通道） | 不注入 | `AvgPool1d(1)` → 256 位置（**1 位置 = 1 格 ≈ 40ms**） |
| e1（128 位置，96 通道） | 不注入 | `AvgPool1d(2)` → 128 位置 |
| e2（64 位置，96 通道） | 不注入 | `AvgPool1d(4)` → 64 位置 |
| mid（64 位置，96 通道） | 唯一注入点 | `AvgPool1d(4)` → 64 位置 |
| 参数量 | 0.4581 M（条件分支 0.0186 M） | **0.4568 M**（条件分支 0.0173 M，比旧结构少 1.3 k） |
| 主干权重 | — | 与 S4 **逐元素相同**（同 `--init-seed 7`，80 个主干键全等，脚本已校验） |

关键代码（`tools/train-diffusion32-align.py`）：

```python
class MultiScaleCondNet(nn.Module):
    def __init__(self, cin=32, cond_dim=32, level_ch=(48,96,96,96), level_pool=(1,2,4,4)):
        self.net = nn.Sequential(Conv1d(cin, cond_dim, 3, padding=1), SiLU(),
                                 Conv1d(cond_dim, cond_dim, 3, padding=1), SiLU())   # 256 位置不变
        self.projs = ModuleList([Conv1d(cond_dim, c, 1) for c in level_ch])          # 每层 1×1 对齐通道
        for p in self.projs: nn.init.normal_(p.weight, std=0.3); nn.init.zeros_(p.bias)

    def forward(self, cond):                    # [B,256,32]
        f = self.net(cond.transpose(1, 2))      # [B,32,256]
        return [proj(f if k == 1 else F.avg_pool1d(f, k))
                for k, proj in zip(self.level_pool, self.projs)]

# UNet1D.forward（multi 分支）
c0, c1, c2, c3 = self.cond_net(cond)
e0 = e0 + c0     # [B,48,256]  ← 1 格分辨率
e1 = e1 + c1     # [B,96,128]
e2 = e2 + c2     # [B,96,64]
m  = m  + c3     # [B,96,64]
```

其余口径**完全不动**：x0 参数化、base 48、temb 128、Fourier 连续难度条件、
未加权 MSE、固定验证 t/噪声、`--threads 1`、`--batch 32`、`--group-cap 300`、
`--cond-drop 0.1`、split 严格按数据集（train∩val 的 song/chart 全为 0，启动强校验）。
`--inject {multi,mid4}` 是唯一开关，两档走同一份代码路径。

### 1.2 为什么这样能解掉 160ms 瓶颈

- 旧分支**先下采样再注入**：每 4 格只取 1 个位置，1 格级的相位信息在进入 U-Net 前就被丢掉；
  下游 `Upsample(nearest)` 只能把 1 个值复制到 4 格，最细只能表达 4 格方块。
- 新分支**先在全分辨率上算好条件，再按层池化注入**：最浅层 e0 是 256 位置，
  且 e0 既是下采样路径的输入、又是 `u2` 的 skip —— 40ms 级差异能直接进到输出层附近。
- 深层仍保留池化后的条件：粗尺度（密度/包络）照样能被利用，两种尺度**同时**在场。

## 3. 验收协议（`tools/eval-align-follow.py`，与 `eval-audio-follow.py` 逐字段对齐）

- **窗口**：val 24 个（`split==1`、seed 20251、每歌 ≤4、按占位率分层），与 round148/151 **同一批窗口**
  （人类行 r250/r1000 复现 0.338/0.504，与 round151 mel 完全一致 → 窗口与算法没漂）。
- **采样**：DDPM 200 步、阈值 0.5、全部对照组**共用同一初始噪声**（seed 20251），只改条件。
- **条件**：32 带 mel onset 通量，「总强度」= 32 带逐格求和。难度条件 = 本窗人类占位率归一化。
- **每组**（两个权重各 7 组，共 14 次采样）：
  配对 / 错配（打乱 song+start_cell 的条件）/ 零条件 / 条件 ±1 格 / 条件 ±4 格。
- **指标**：
  1. `r250` / `r1000`：生成占用与条件总强度按 250ms / 1000ms 分箱后的 Pearson（逐窗算，报中位）；
  2. `p_odd_hi`：音符落在 1/32 细分格（全局格号为奇数）**且**该格条件总强度高于窗内中位的比例（池化）；
  3. `r@1格`（本轮新增）：**1 格分箱**的 Pearson —— 因为 190BPM 下 250ms ≈ 6.3 格，
     `r250` 天生看不见 1 格级相位，必须单独量 40ms 尺度；
  4. 结构诊断 `tools/diag-align-impulse.py`：条件单格脉冲的输出响应宽度（不采样，直接测 Jacobian 形状）。
- **统计**：逐窗配对差 + Wilcoxon 符号秩；`p_odd_hi` 另做**按窗口 bootstrap**（2000 次重采样窗口、池化计数）。
- 人类参照行、结构零假设（均匀音符）都在同一脚本里现算：
  **人类 `p_odd_hi` = 0.8039**（4 带口径 round148 报的是 0.813），**均匀音符基线 = 0.6299**（4 带 0.639）。

### 4.3 ±1 格与 ±4 格平移：输出到底跟不跟？

判据：把喂进去的条件整体平移 k 格后，
**「对给定 C」= 生成结果与它拿到的那个条件的对齐**（跟住了 → 不降），
**「对真 C」= 与本窗真谱的对齐**（跟住了 → 应该降，因为条件已经不是真谱了）。

**1 格分箱（40ms 尺度，val 24 窗中位）**

| 组 | 对给定 C | 对真 C | 读数 |
| --- | --- | --- | --- |
| S1-配对（基准） | 0.504 | 0.504 | — |
| **S1 +1 格** | **0.150** | **−0.019** | **输出跟着条件往 +1 格移动**（对真 C 塌到 0） |
| S1 −1 格 | 0.107 | 0.012 | 跟着往 −1 格移动 |
| **S4 +1 格** | **−0.122** | **0.243** | **输出没动**（还对着真 C；与给定条件反相关） |
| S4 −1 格 | −0.112 | 0.276 | 没动 |
| S1 +4 格 | 0.457 | 0.368 | 跟着 +4 格移动 |
| S4 +4 格 | 0.426 | 0.262 | 跟着 +4 格移动 |
| S1 −4 格 | 0.503 | 0.375 | 跟着 −4 格移动 |
| S4 −4 格 | 0.463 | 0.275 | 跟着 −4 格移动 |

**这就是相位分辨率的直接证据**：

- **±1 格**：S1 的对给定 C（0.150）高于对真 C（−0.019）→ 输出被条件带走了 1 格；
  S4 反过来（对真 C 0.243 > 对给定 C −0.122）→ 输出原地不动，1 格平移在它那里**不可表示**。
- **±4 格**：两档都是对给定 C 保持、对真 C 下降 → 4 格平移**两档都能表示**
  （旧分支一个 stride 单位正好是 4 格，符合预期）。

### 4.5 结构诊断：条件单格脉冲的输出响应（`tools/diag-align-impulse.py`）

不采样，直接问「把条件里某一格（≈40ms）抬高 0.5，模型输出在时间轴上响应多宽」。
8 个 val 窗 × 32 个随机脉冲位置，x_t 用真实窗 + 固定噪声（t=100），只差条件扰动：

| 权重 | 峰值 \|Δx0\| | 归一化响应 @±1 | @±2 | @±4 |
| --- | --- | --- | --- | --- |
| **S1** | **0.174** | 0.29 | 0.25 | **0.13** |
| **S4** | 0.078 | 0.31 | 0.34 | **0.36** |

- S1：响应在脉冲格处最尖（1.00），±1 掉到 0.29、±4 掉到 0.13 → **局部化，宽度 ≈1 格**。
- S4：响应从 ±1 到 ±4 **几乎一样平**（0.31 / 0.34 / 0.36）→ 单格扰动被摊到 ≥4 格宽的方块里，
  **这正是 `k=4,s=4` 投影把 1 格信息压成 4 格块的直接形状证据**。
- 顺带：S1 的峰值响应是 S4 的 **2.2 倍**（0.174 vs 0.078）—— 条件对输出的因果影响力本身就大一倍。

## 5. 结论：相位分辨率从 160ms 提升到 ~40ms 了吗？

**是 —— 结构上完全做到，行为上做到了相当一部分（test 上已与人类不可区分），但没有全部。**

1. **架构瓶颈已解除（结构层面）**：S1 最浅层注入 256 位置条件，单格条件脉冲的输出响应
   局部化在 1 格（S4 平铺 ≥4 格）；±1 格平移时 S1 的输出真的跟着条件移动、S4 不动；
   S1 对 1 格平移的输出敏感度是 4 格的 2.8 倍，S4 是 1.1 倍（无差别）。
   这说明「条件里的 40ms 相位」现在**能**被网络表示和使用 —— 这正是任务要修的瓶颈。
2. **val 上行为显著改善（主判据）**：`p_odd_hi` 0.7653 vs 0.7401（+0.0252，CI [+0.007,+0.049]，p=0.0005）；
   1 格对齐 0.504 vs 0.440（+0.039，p=0.022）；±1 格退化 −0.52 vs −0.16（p=2.4e-07）。
3. **test 上更强、且与人类不可区分**：`p_odd_hi` 0.7812 vs 0.7294（+0.0518，p<1e-4）；
   1 格对齐 0.544 vs 0.322（+0.118，p=1.7e-4）；
   S1 与人类 0.8106 的差 **−0.029，CI 含 0（不显著）**，S4 与人类的差 −0.081 **显著**。
   即：在未参与选模的 test 上，S1 的 1/32 踩格水平**已经统计上无法与人类区分**，
   而 S4 仍然显著更低；S4 对 ±1 格平移完全不退化（p=0.57），S1 显著退化（p=0.0042）。
4. **诚实的边界**：
   - **包络指标（r250/r1000）两档无显著差**（val：+0.007，p=0.97）——
     多尺度注入买到的全部是「细相位」，不是「更大的跟随幅度」；
     test 上 r250 +0.066（p=0.097）也只是边缘。
   - **val 上 S1 仍显著低于人类**（`p_odd_hi` −0.039，p=0.025；1 格对齐 −0.096，p=0.012），
     只补上 S4→人类差距的 36–39%；val 是选模集，对两档都偏乐观。
5. **所以正确的说法**：条件分支的**可表示相位分辨率**从 4 格（≈160ms）提升到 1 格（≈40ms），
   并且**行为上确实学到了 1/32 格级的踩格结构**（val 显著、test 与人类不可区分）；
   剩下的差距不再是架构问题，而是训练量/数据量（round151 的诊断：「对齐信号被密度先验淹没」），
   外加 `p_odd_hi`/1 格对齐这类细尺度指标本身噪声大（24 窗下 CI 宽度约 ±0.04）——
   **瓶颈已经从架构移到了预算与评估分辨率**。
